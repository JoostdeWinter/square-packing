# Comparison and coordinate sources

The numerical snapshot was assembled on 17 November 2026. The two large-count repositories cover n up to 10,000. The Kaggle leaderboard covers the first 1,000. The Squares Project’s main atlas has 324 rows. The source identifiers below refer to the immediate author or provider of the dataset. Earlier constructions can occur in several datasets.
